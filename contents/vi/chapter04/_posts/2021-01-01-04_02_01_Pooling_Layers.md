# Tầng Gộp và Kiến trúc CNN

Bây giờ ta đã hiểu tầng tích chập, cần thêm hai mảnh để xây CNN hoàn chỉnh: **tầng gộp** (*pooling*) để giảm mẫu và **các mẫu thiết kế kiến trúc** kết hợp các thành phần này hiệu quả. Bài này đi sâu vào các phép gộp và lần theo tiến hóa kiến trúc CNN từ LeNet đến các thiết kế hiện đại.

---

## 1. Tầng Gộp: Tổng quan Khái niệm

**Gộp** (*pooling*, còn gọi là lấy mẫu con hoặc giảm mẫu) giảm kích thước không gian của bản đồ đặc trưng trong khi giữ thông tin quan trọng nhất. Điều này phục vụ nhiều mục đích then chốt:

1. **Giảm chiều**: Bản đồ đặc trưng nhỏ hơn nghĩa là ít tham số và ít tính toán hơn ở các tầng sau
2. **Bất biến tịnh tiến**: Các dịch chuyển nhỏ trên đầu vào cho cùng đầu ra đã gộp
3. **Ức chế nhiễu**: Lấy trung bình hoặc max giảm độ nhạy với biến thiên nhỏ
4. **Tăng trường tiếp nhận**: Mỗi điểm ảnh đã gộp đại diện cho vùng lớn hơn của đầu vào gốc

**Hiểu biết then chốt**: Gộp hoạt động như một dạng “tóm tắt” — ta không cần mọi chi tiết điểm ảnh để nhận ra con mèo. Ta cần các đặc trưng cốt yếu, và gộp trích xuất chúng trong khi loại bỏ thông tin dư thừa.

## 2. Nền tảng toán học
### Max Pooling

**Max pooling** lấy giá trị lớn nhất trong mỗi vùng gộp:

$$\text{MaxPool}(X)_{i,j} = \max_{m,n \in R_{i,j}} X_{m,n}$$

Trong đó $$R_{i,j}$$ là vùng gộp (thường 2×2) tại vị trí đầu ra $$(i,j)$$.

**Ví dụ trực quan với gộp 2×2, stride 2**:

```
Đầu vào (4×4):              Đầu ra (2×2):

┌─────┬─────┬─────┬─────┐
│  1  │  3  │  2  │  4  │     ┌─────┬─────┐
├─────┼─────┼─────┼─────┤     │  6  │  8  │
│  5  │  6  │  7  │  8  │ →   ├─────┼─────┤
├─────┼─────┼─────┼─────┤     │  3  │  4  │
│  0  │  2  │  1  │  3  │     └─────┴─────┘
├─────┼─────┼─────┼─────┤
│  1  │  3  │  2  │  4  │
└─────┴─────┴─────┴─────┘

Vùng [0:2, 0:2] = [[1,3],[5,6]] → max = 6
Vùng [0:2, 2:4] = [[2,4],[7,8]] → max = 8
Vùng [2:4, 0:2] = [[0,2],[1,3]] → max = 3
Vùng [2:4, 2:4] = [[1,3],[2,4]] → max = 4
```

**Tính chất của max pooling**:
- Giữ các kích hoạt mạnh nhất (đặc trưng trội)
- Cung cấp một phần bất biến tịnh tiến
- Giới thiệu một dạng phi tuyến
- **Không có tham số học được**

### Average Pooling

**Average pooling** tính trung bình của mỗi vùng gộp:

$$\text{AvgPool}(X)_{i,j} = \frac{1}{|R_{i,j}|} \sum_{m,n \in R_{i,j}} X_{m,n}$$

**Ví dụ trực quan**:

```
Đầu vào (4×4):              Đầu ra (2×2):

┌─────┬─────┬─────┬─────┐
│  1  │  3  │  2  │  4  │     ┌───────┬───────┐
├─────┼─────┼─────┼─────┤     │ 3.75  │ 5.25  │
│  5  │  6  │  7  │  8  │ →   ├───────┼───────┤
├─────┼─────┼─────┼─────┤     │ 1.50  │ 2.50  │
│  0  │  2  │  1  │  3  │     └───────┴───────┘
├─────┼─────┼─────┼─────┤
│  1  │  3  │  2  │  4  │
└─────┴─────┴─────┴─────┘

Vùng [0:2, 0:2] = [[1,3],[5,6]] → mean = 15/4 = 3.75
Vùng [0:2, 2:4] = [[2,4],[7,8]] → mean = 21/4 = 5.25
```

**Tính chất của average pooling**:
- Xem xét mọi giá trị (không có thông tin bị loại bỏ hoàn toàn)
- Gradient mượt hơn trong lan truyền ngược
- Tốt hơn để giữ thông tin nền
- Ít phổ biến trong phân loại, nhiều hơn trong phân đoạn

### Max Pooling so với Average Pooling: Khi nào Dùng Cái nào?

| Khía cạnh | Max Pooling | Average Pooling |
|--------|-------------|-----------------|
| **Giữ** | Đặc trưng trội | Cường độ tổng thể |
| **Gradient** | Thưa (chỉ qua max) | Dày (qua tất cả) |
| **Tác vụ** | Phân loại (tìm đặc trưng phân biệt nhất) | Phân đoạn, ước lượng độ sâu |
| **Dùng hiện đại** | Tầng sớm/giữa | Global pooling ở cuối |

**Kết quả thực nghiệm**: Max pooling thường tốt hơn cho phân loại vì các đặc trưng phân biệt nhất (kích hoạt cực đại) hữu ích nhất để phân biệt giữa các lớp.

### Global Average Pooling (GAP)

**Global Average Pooling** lấy trung bình mỗi bản đồ đặc trưng nguyên vẹn thành một giá trị:

$$\text{GAP}(X)_c = \frac{1}{H \times W} \sum_{i=1}^{H} \sum_{j=1}^{W} X_{i,j,c}$$

**Ví dụ trực quan**:

```
Đầu vào (7×7×512):                    Đầu ra (512,):

┌─────────────────────────────┐
│  Bản đồ Đặc trưng 1 (7×7)   │ →  [0.42]
├─────────────────────────────┤
│  Bản đồ Đặc trưng 2 (7×7)   │ →  [0.78]
├─────────────────────────────┤
│         ...                 │      ...
├─────────────────────────────┤
│  Bản đồ Đặc trưng 512 (7×7) │ →  [0.31]
└─────────────────────────────┘

Mỗi bản đồ 7×7 → một số (trung bình của nó)
Kết quả: vectơ 512 chiều
```

**Vì sao GAP mang tính cách mạng** (từ Network in Network, 2014):

1. **Không cần tầng kết nối đầy đủ**: Giảm tham số mạnh
2. **Tổng quát hóa tốt hơn**: Hoạt động như chính quy hóa cấu trúc
3. **Dễ diễn giải hơn**: Mỗi bản đồ đặc trưng có thể liên kết trực tiếp với một lớp
4. **Linh hoạt kích thước đầu vào**: Mô hình có thể nhận bất kỳ kích thước đầu vào nào (khi suy luận)

**Trước GAP** (AlexNet, VGG):
```
Tầng Conv → Flatten (4096 giá trị) → FC (4096→4096) → FC (4096→1000)
Tham số ở các tầng FC: 4096×4096 + 4096×1000 ≈ 20 triệu
```

**Với GAP** (ResNet, CNN hiện đại):
```
Tầng Conv → GAP (512 giá trị) → FC (512→1000)
Tham số: 512×1000 = 512,000
```

**Ít hơn khoảng 40× tham số** chỉ từ thay đổi này!

### Kích thước Đầu ra cho Pooling

Cùng công thức như tích chập áp dụng:

$$H_{out} = \left\lfloor \frac{H_{in} + 2p - k}{s} \right\rfloor + 1$$

Với max pooling 2×2 chuẩn, stride 2:
- $$k = 2, s = 2, p = 0$$
- $$H_{out} = \lfloor (H_{in} - 2) / 2 \rfloor + 1 = H_{in} / 2$$

**Kích thước không gian giảm một nửa** (giả sử kích thước chẵn).

## 3. Cài đặt Mã

### Cài đặt NumPy

```python
import numpy as np

def max_pool2d(input_array, pool_size=2, stride=2):
    """
    Phép max pooling.
    
    Args:
        input_array: Đầu vào dạng (H, W) hoặc (H, W, C)
        pool_size: Kích thước cửa sổ gộp
        stride: Bước nhảy của phép gộp
    
    Returns:
        Đầu ra đã gộp
    """
    # Xử lý trường hợp một kênh
    if input_array.ndim == 2:
        input_array = input_array[:, :, np.newaxis]
        squeeze_output = True
    else:
        squeeze_output = False
    
    H, W, C = input_array.shape
    
    # Tính kích thước đầu ra
    H_out = (H - pool_size) // stride + 1
    W_out = (W - pool_size) // stride + 1
    
    output = np.zeros((H_out, W_out, C))
    
    for i in range(H_out):
        for j in range(W_out):
            h_start = i * stride
            w_start = j * stride
            
            # Trích vùng gộp và lấy max
            region = input_array[h_start:h_start+pool_size, 
                                w_start:w_start+pool_size, :]
            output[i, j, :] = np.max(region, axis=(0, 1))
    
    if squeeze_output:
        output = output[:, :, 0]
    
    return output


def avg_pool2d(input_array, pool_size=2, stride=2):
    """Phép average pooling."""
    if input_array.ndim == 2:
        input_array = input_array[:, :, np.newaxis]
        squeeze_output = True
    else:
        squeeze_output = False
    
    H, W, C = input_array.shape
    H_out = (H - pool_size) // stride + 1
    W_out = (W - pool_size) // stride + 1
    
    output = np.zeros((H_out, W_out, C))
    
    for i in range(H_out):
        for j in range(W_out):
            h_start = i * stride
            w_start = j * stride
            
            region = input_array[h_start:h_start+pool_size, 
                                w_start:w_start+pool_size, :]
            output[i, j, :] = np.mean(region, axis=(0, 1))
    
    if squeeze_output:
        output = output[:, :, 0]
    
    return output


def global_avg_pool2d(input_array):
    """
    Global average pooling: trung bình mỗi kênh thành một giá trị.
    
    Args:
        input_array: Dạng (H, W, C)
    
    Returns:
        Vectơ dạng (C,)
    """
    return np.mean(input_array, axis=(0, 1))


# ============== DEMO ==============
print("=" * 50)
print("Demo các Phép Gộp")
print("=" * 50)

# Tạo đầu vào mẫu
input_data = np.array([
    [1, 3, 2, 4],
    [5, 6, 7, 8],
    [0, 2, 1, 3],
    [1, 3, 2, 4]
], dtype=np.float32)

print(f"Đầu vào (4×4):\n{input_data}\n")

# Max pooling
max_pooled = max_pool2d(input_data, pool_size=2, stride=2)
print(f"Max pooling (2×2, stride 2):\n{max_pooled}\n")

# Average pooling
avg_pooled = avg_pool2d(input_data, pool_size=2, stride=2)
print(f"Average pooling (2×2, stride 2):\n{avg_pooled}\n")

# Global average pooling (đa kênh)
multi_channel = np.random.randn(7, 7, 512).astype(np.float32)
gap_output = global_avg_pool2d(multi_channel)
print(f"Global average pooling:")
print(f"  Shape đầu vào: {multi_channel.shape}")
print(f"  Shape đầu ra: {gap_output.shape}")
print(f"  5 giá trị đầu: {gap_output[:5]}")
```

### Cài đặt PyTorch

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

# ============== CÁC TẦNG GỘP CÓ SẴN ==============

# Max pooling
max_pool = nn.MaxPool2d(kernel_size=2, stride=2)

# Average pooling
avg_pool = nn.AvgPool2d(kernel_size=2, stride=2)

# Global average pooling (adaptive - hoạt động với mọi kích thước đầu vào)
global_avg_pool = nn.AdaptiveAvgPool2d(1)  # Kích thước đầu ra 1×1

# Global max pooling
global_max_pool = nn.AdaptiveMaxPool2d(1)


# ============== DEMO ==============
print("Ví dụ Gộp PyTorch")
print("=" * 50)

# Tạo đầu vào mẫu: batch 2, 64 kênh, 32×32
x = torch.randn(2, 64, 32, 32)
print(f"Shape đầu vào: {x.shape}")

# Áp dụng các phép gộp khác nhau
max_out = max_pool(x)
avg_out = avg_pool(x)
gap_out = global_avg_pool(x)

print(f"Sau MaxPool2d(2,2): {max_out.shape}")      # (2, 64, 16, 16)
print(f"Sau AvgPool2d(2,2): {avg_out.shape}")      # (2, 64, 16, 16)
print(f"Sau GAP: {gap_out.shape}")                 # (2, 64, 1, 1)
print(f"Sau GAP + squeeze: {gap_out.squeeze(-1).squeeze(-1).shape}")  # (2, 64)


# ============== GỘP KÈM CHỈ SỐ (cho unpooling) ==============

# MaxPool có thể trả về chỉ số cho các phép unpooling
max_pool_with_idx = nn.MaxPool2d(kernel_size=2, stride=2, return_indices=True)
pooled, indices = max_pool_with_idx(x)

print(f"\nMax pooling kèm chỉ số:")
print(f"  Shape đã gộp: {pooled.shape}")
print(f"  Shape chỉ số: {indices.shape}")

# Unpooling (hữu ích cho mạng phân đoạn như U-Net)
unpool = nn.MaxUnpool2d(kernel_size=2, stride=2)
unpooled = unpool(pooled, indices)
print(f"  Shape unpooled: {unpooled.shape}")


# ============== SO SÁNH: POOLING so với CONV STRIDE ==============
print("\n" + "=" * 50)
print("Pooling so với Tích chập Stride")
print("=" * 50)

# Truyền thống: Conv → Pool
conv_then_pool = nn.Sequential(
    nn.Conv2d(64, 128, kernel_size=3, padding=1),  # 32×32 → 32×32
    nn.MaxPool2d(2, 2)                              # 32×32 → 16×16
)

# Hiện đại: Conv stride (giảm mẫu học được)
strided_conv = nn.Conv2d(64, 128, kernel_size=3, stride=2, padding=1)  # 32×32 → 16×16

x_test = torch.randn(2, 64, 32, 32)

out_pool = conv_then_pool(x_test)
out_strided = strided_conv(x_test)

print(f"Đầu vào: {x_test.shape}")
print(f"Conv + MaxPool: {out_pool.shape}")
print(f"Conv Stride: {out_strided.shape}")

# So sánh tham số
pool_params = sum(p.numel() for p in conv_then_pool.parameters())
strided_params = sum(p.numel() for p in strided_conv.parameters())
print(f"\nTham số - Conv+Pool: {pool_params}, Conv Stride: {strided_params}")
print("(Cùng số tham số, nhưng conv stride học được phép giảm mẫu!)")
```
