> *For decades, building an AI system meant locking domain experts in a room to hand-craft brittle rules—edge filters for vision, phonetic templates for speech, grammar trees for text. Deep learning flipped that paradigm on its head: instead of telling the machine what features to look for, we give it a differentiable hierarchy of layers and let data sculpt the features automatically.*

## Key ideas: Entering the Deep Learning Paradigm

1. **Representation Learning (Features from Data)**: Replaces manual feature engineering with stacked nonlinear transformations $$f = f_L \circ \dots \circ f_1$$ that learn edges, textures, parts, and semantics directly from raw tensors.
2. **End-to-End Differentiable Training**: Connects raw inputs to task losses through a single computational graph so gradient signals flow backwards and adapt every intermediate representation to the final objective.
3. **Empirical Scaling (Data, Compute, and Model Capacity)**: Explains why deep architectures outperform classical models once dataset size and GPU parallelism cross critical thresholds, while remaining data-hungry in tiny-data regimes.
4. **Systems & Workflow Discipline**: Pairs mathematical understanding with disciplined engineering—reproducible seeds, baseline benchmarks, clean train/val/test splits, and quantitative error analysis.

### Worked example: How Two Nonlinear Layers Learn a Representation That a Linear Model Cannot

Consider the classic 1D non-linearly separable dataset: $$x \in \{-2, 0, +2\}$$ with binary labels $$y = (1, 0, 1)$$ (positive if $$\lvert x\rvert \geq 1$$). No single linear threshold $$wx + b > 0$$ can separate $$0$$ from both $$-2$$ and $$+2$$.

1. **Hidden Representation Layer (2 ReLU Neurons)**:
   Define $$h_1(x) = \text{ReLU}(x - 1)$$ and $$h_2(x) = \text{ReLU}(-x - 1)$$.
   Evaluate on all three inputs:
   - At $$x = -2$$: $$h_1 = \text{ReLU}(-3) = 0$$, $$h_2 = \text{ReLU}(+1) = 1 \implies \mathbf{h} = (0, 1)$$.
   - At $$x = 0$$: $$h_1 = \text{ReLU}(-1) = 0$$, $$h_2 = \text{ReLU}(-1) = 0 \implies \mathbf{h} = (0, 0)$$.
   - At $$x = +2$$: $$h_1 = \text{ReLU}(+1) = 1$$, $$h_2 = \text{ReLU}(-3) = 0 \implies \mathbf{h} = (1, 0)$$.
2. **Output Linear Classifier on the Learned Features**:
   Compute $$z = h_1 + h_2 - 0.5$$:
   - At $$x = -2$$: $$z = 0 + 1 - 0.5 = +0.5 > 0 \implies \hat{y} = 1$$.
   - At $$x = 0$$: $$z = 0 + 0 - 0.5 = -0.5 < 0 \implies \hat{y} = 0$$.
   - At $$x = +2$$: $$z = 1 + 0 - 0.5 = +0.5 > 0 \implies \hat{y} = 1$$.
3. **Key Insight**:
   The hidden layer folded the real line so that both outer points mapped to $$h_1 + h_2 = 1$$ while the center mapped to $$0$$—making a non-linearly separable problem trivial for a linear readout head.
