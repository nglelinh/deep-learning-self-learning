# Chapter 08 — The Transformer Architecture

![Transformer Architecture](/deep-learning-self-learning/img/chapter_img/chapter08/transformer_architecture.png)
*Full Transformer (encoder–decoder) from “Attention Is All You Need.” Source: Wikimedia Commons*

## Why this chapter exists

Chapter 07 built **attention** as a general mechanism: soft lookup with queries, keys, and values. The Transformer takes that idea to its logical extreme: **almost the entire architecture is attention**, plus small position-wise MLPs, residuals, and normalization.

That design choice solved three chronic problems of RNN sequence models at once:

1. **Parallelism** — all positions process in one matrix-parallel step (no left-to-right loop at training time).  
2. **Long-range paths** — any token can influence any other token in a single layer ($$O(1)$$ path length).  
3. **Scalability** — the same block stacks cleanly to tens or hundreds of layers and transfers across tasks.

The result is the dominant template of modern AI: BERT-style encoders, GPT-style decoders, T5-style encoder–decoders, Vision Transformers, and many multimodal systems.

![Transformer overview + Multi-Head](/deep-learning-self-learning/img/chapter_img/chapter08/sa_transformer_multihead_overview.jpg)
*Figure: Encoder–decoder with multi-head attention (several scaled-dot-product heads in parallel). (Illustration from an intro Transformer / Self-Attention video)*

**Link to Chapter 18 (word embeddings):** Word2Vec/GloVe assign **one** fixed vector per word type. Transformers/BERT produce **contextual** representations — the same token “Apple” (fruit vs company) gets different vectors depending on the sentence. Attention (Chapters 07–08) is the mechanism that mixes that context.

![Cross vs Masked](/deep-learning-self-learning/img/chapter_img/chapter08/tf_cross_vs_masked_labels.jpg)
*Figure: **Cross-attention** (K,V from encoder, Q from decoder) vs **masked self-attention**. (Illustration from a Transformer Attention video)*

![Cross-attention: K,V from encoder](/deep-learning-self-learning/img/chapter_img/chapter08/tf_cross_attn_kv_from_encoder.jpg)
*Figure: K/V flow from the encoder into the decoder via cross-attention. (Illustration from a Transformer Attention video)*

**Positional encoding (PE):** self-attention is order-blind if it only sees token content. Sin-cos PE gives each $$pos$$ a multi-frequency vector, then **adds** it to the token embedding — full step-by-step ($$pos$$, $$i$$, sin/cos, $$d=512$$) in the Transformer Theory lesson.

## Learning goals

By the end of this chapter you should be able to:

- Draw the **encoder stack**, **decoder stack**, and data flow between them.
- Explain **self-attention**, **masked self-attention**, and **cross-attention** roles.
- Derive and implement **positional encodings** (why pure attention is order-blind).
- Write the equations for a full **Transformer layer** (attention + FFN + residual + norm).
- Implement a small Transformer in PyTorch with correct masks and shapes.
- Name the core papers (Vaswani, BERT, GPT-2, ViT) and common training/inference pitfalls (warmup, KV-cache, quadratic cost).

## Mental model

Think of a Transformer layer as two operators stacked repeatedly:

1. **Communicate** — multi-head attention mixes information across positions.  
2. **Compute** — a position-wise feed-forward network transforms each position independently.

Order is injected once (or continuously, in relative-PE variants) so that “who talks to whom” can depend on sequence structure, not only on content.

When you can walk through *one* encoder layer and *one* decoder step with masks drawn on paper, you are ready for the theory and code lessons that follow.
