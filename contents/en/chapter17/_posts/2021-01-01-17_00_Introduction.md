Knowing that a photograph contains a "pedestrian" is useless to a self-driving car unless it also knows *where* the pedestrian is to the nearest pixel, *how many* there are, and *which* silhouette belongs to whom. Computer vision applications ascend a clear hierarchy of spatial granularity—from whole-image classification, to bounding-box object detection, to pixel-wise semantic and instance segmentation—each requiring specialized architectural heads and geometric loss functions.

## Key ideas: The Spatial Hierarchy of Computer Vision Tasks

- **Pillar 1 — Spatial Localization & Object Detection**: Combines class prediction with continuous coordinate regression $(x, y, w, h)$ across variable numbers of objects using one-stage (YOLO) or two-stage (Faster R-CNN) pipelines.
- **Pillar 2 — Dense Pixel Prediction (Semantic Segmentation)**: Preserves fine spatial resolution via encoder–decoder skip connections (U-Net) or dilated/atrous convolutions (DeepLab) to assign a class label to every pixel.
- **Pillar 3 — Instance-Level Separation (Mask R-CNN & Panoptic)**: Disentangles overlapping objects of the *same* class by pairing box proposals with per-instance binary mask heads and RoIAlign.
- **Pillar 4 — Multi-Scale Feature Pyramids (FPN)**: Fuses high-resolution shallow maps (for tiny distant objects) with semantically rich deep maps (for large objects) so detectors work seamlessly across scales.

### Worked example: Computing Pixel IoU (mIoU) for a $2 \times 2$ Semantic Segmentation Mask

Suppose a 2-class segmentation model (Class 0: background, Class 1: road) predicts mask $\hat{Y} = \begin{bmatrix}1 & 1\\ 0 & 1\end{bmatrix}$ against ground truth $Y = \begin{bmatrix}1 & 0\\ 0 & 1\end{bmatrix}$.

1. **Class 1 (road) IoU**:
   - True Positives (both 1): 2 pixels (top-left, bottom-right).
   - Union (either 1): 3 pixels (top-left, top-right, bottom-right).
   $$\text{IoU}_1 = \frac{2}{3} \approx 0.6667.$$
2. **Class 0 (background) IoU**:
   - True Positives (both 0): 1 pixel (bottom-left).
   - Union (either 0): 2 pixels (top-right, bottom-left).
   $$\text{IoU}_0 = \frac{1}{2} = 0.5000.$$
3. **Mean IoU (mIoU) vs. Pixel Accuracy**:
   $$\text{Pixel Accuracy} = \frac{3}{4} = 75.0\%, \qquad \text{mIoU} = \frac{0.6667 + 0.5000}{2} = 58.33\%.$$
4. **Takeaway**: Pixel accuracy ($75\%$) flatters imbalanced masks, whereas mIoU ($58.3\%$) strictly penalizes both false positives and false negatives on every class equally.
