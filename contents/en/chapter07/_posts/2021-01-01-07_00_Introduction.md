# Chapter 07 — Attention Mechanisms

![Attention Encoder-Decoder](/deep-learning-self-learning/img/chapter_img/chapter07/attention_encoder_decoder.png)
*Encoder–decoder with attention: the decoder looks back over all encoder states at each generation step. Source: Wikimedia Commons*

## Why this chapter exists

Recurrent models (Chapters 5–6) process sequences step by step and compress history into a hidden state. That design works, but it creates two chronic problems for long sequences:

1. **Information bottleneck** — especially in classic encoder–decoder models, where the whole source must fit in one fixed vector.
2. **Hard long-range routing** — information from position $$i$$ to position $$j$$ must travel through many sequential steps, which is fragile under vanishing gradients.

**Attention** attacks both problems with one idea: *dynamically re-read* the relevant parts of the input (or of the sequence itself) when forming each representation or prediction. Instead of one frozen summary, the model learns a soft distribution over positions and forms a weighted combination of their features.

That idea began as an add-on to RNN translation systems. It then became the computational heart of **Transformers**, which power modern language models, many vision systems, and multimodal architectures. This chapter builds attention from first principles so the Transformer chapter is a composition of familiar pieces, not a black box.

### Quick map: 4 attention flavors in Transformers

| Kind | Q from | K, V from | Mask? |
|------|--------|-----------|--------|
| **Self-attention** | same sequence | same sequence | optional (full / pad) |
| **Masked (causal) self-attention** | decoder | decoder | block the “future” |
| **Cross-attention** | decoder | encoder | usually pad only |
| **Multi-head** | as above, several heads in parallel | as above | as above |

### Self-attention in plain language: “which words relate to which?”

Sentences with ambiguous words (e.g. “Apple” = fruit vs tech company) only resolve when you **look at the other tokens**. Self-attention is the mechanism that assigns “attention arcs” among tokens in the same sentence.

![Context attention arcs](/deep-learning-self-learning/img/chapter_img/chapter07/sa_context_arcs_disambiguation.jpg)
*Figure: Words such as “orange” / “phone” pull attention toward “Apple” in the company sense. (Illustration from an intro Transformer / Self-Attention video)*

### LLM view: a “fully connected relational computation network”

In large language models, embeddings give each token a vector; **attention** is the layer where tokens *talk* to each other: every position can link to every other position (a full / fully connected graph), with **dynamic** link weights driven by content.

![Title: attention = fully connected relations](/deep-learning-self-learning/img/chapter_img/chapter07/llm_attn_title_fully_connected.jpg)

## Learning goals

By the end of this chapter you should be able to:

- Explain the encoder–decoder bottleneck and how attention removes it.
- Write the general attention pattern: **scores → softmax weights → weighted values**.
- Contrast **Bahdanau (additive)** and **Luong (multiplicative)** attention.
- Use the **query / key / value** language for both cross-attention and self-attention.
- Derive why **scaled** dot-product attention needs $$1/\sqrt{d_k}$$.
- Implement attention and multi-head attention with correct shapes, masks, and numerical stability.
- Name the classic papers and the failure modes that break real systems (padding, causal masks, missing scale).

## Mental model to keep

Attention is **content-addressable soft memory**:

- **Query** = what you are looking for now  
- **Keys** = what each memory slot offers for matching  
- **Values** = what you retrieve if that slot matches  

Everything else—Bahdanau vs Luong, multi-head, causal masks—is a design choice around that core loop.

When you can draw that loop on paper for both *translation* (decoder attends to encoder) and *self-attention* (sequence attends to itself), you are ready for the rest of the chapter—and for Transformers.
