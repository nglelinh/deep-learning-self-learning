Images live on neat 2D grids and text lives on 1D lines—so CNNs and RNNs always know which pixel is "above" or which word comes "next." Now look at a caffeine molecule, a citation network, or a fraud ring: there is no "left" or "right," every node has a different number of neighbors, and relabeling node 1 as node 7 does not change the object at all. Graph Neural Networks (GNNs) generalize deep learning to arbitrary relational structures by enforcing **permutation equivariance** through iterative neighborhood message passing.

## Key ideas: Foundations of Deep Learning on Graphs

- **Pillar 1 — Graph Representations & Adjacency Algebra**: Encodes structure via adjacency matrix $A \in \{0,1\}^{N \times N}$, degree matrix $D$, graph Laplacian $L = D - A$, and node feature matrix $X \in \mathbb{R}^{N \times F}$.
- **Pillar 2 — Permutation Invariance & Equivariance**: Guarantees that shuffling node indices $P X, P A P^\top$ produces identically shuffled node embeddings $P H$ (node tasks) or unchanged graph predictions (graph tasks).
- **Pillar 3 — Message Passing Neural Networks (MPNN)**: Unifies GCN, GraphSAGE, and GAT into three differentiable steps: compute neighbor messages, aggregate with a permutation-invariant reducer (sum/mean/max/attention), and update node states.
- **Pillar 4 — Graph Task Taxonomy**: Separates node classification (fraud detection), link prediction (recommendations), and graph-level property prediction (molecular toxicity).

### Worked example: Checking Permutation Equivariance on a 3-Node Path Graph

Consider a 3-node path $1 - 2 - 3$ with adjacency matrix $A = \begin{bmatrix}0&1&0\\1&0&1\\0&1&0\end{bmatrix}$ and scalar node features $x = \begin{bmatrix}10\\20\\30\end{bmatrix}$.

1. **One step of raw neighbor-sum message passing $h = Ax$**:
   $$h = \begin{bmatrix}0&1&0\\1&0&1\\0&1&0\end{bmatrix}\begin{bmatrix}10\\20\\30\end{bmatrix} = \begin{bmatrix}20\\40\\20\end{bmatrix}.$$
   (Node 2 receives $10 + 30 = 40$; endpoints receive $20$.)
2. **Permute node order by swapping node 1 and node 3** ($P = \begin{bmatrix}0&0&1\\0&1&0\\1&0&0\end{bmatrix}$):
   $x' = Px = [30, 20, 10]^\top$, $A' = PAP^\top = A$.
   $$h' = A'x' = \begin{bmatrix}20\\40\\20\end{bmatrix} = Ph.$$
3. **Graph-level readout via sum pooling**: $\sum h_i = \sum h'_i = 80$ (strictly permutation **invariant**!).
4. **Takeaway**: Matrix multiplication by $A$ paired with symmetric aggregators mathematically guarantees that node-ID ordering can never corrupt a GNN's predictions.

Graph Neural Networks (GNNs) extend deep learning to graph-structured data: social networks, molecules, knowledge graphs, and recommendation systems. This chapter covers graph representations, message passing, Graph Convolutional Networks (GCN), GraphSAGE, Graph Attention Networks (GAT), and applications in node classification, link prediction, and graph generation.
