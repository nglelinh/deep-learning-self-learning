A famous wolf-vs-husky classifier achieved 95% test accuracy—until researchers ran an explanation map and discovered it was completely ignoring the animals and only looking at whether there was snow in the background. In medicine, finance, and autonomous driving, high test accuracy is never enough if the model relies on brittle shortcuts ("Clever Hans" features). Interpretability and Explainable AI (XAI) turn opaque neural networks into auditable instruments by attributing predictions to input pixels, tokens, and internal circuits.

## Background Knowledge Map: Foundations of Neural Network Interpretability

- **Pillar 1 — Local vs. Global Explanations**: Separates explaining *one specific prediction* (saliency maps, LIME, SHAP) from understanding *general learned concepts* across the whole network (feature visualization, concept activation vectors).
- **Pillar 2 — Gradient & Backpropagation Attribution**: Uses local first-order sensitivity $\nabla_x f_c(x)$, Integrated Gradients, and Grad-CAM to highlight which pixels or tokens move the target class logit.
- **Pillar 3 — Perturbation & Game-Theoretic Attribution**: Measures feature importance by masking inputs and averaging marginal contributions over subsets (LIME surrogate models, Shapley values).
- **Pillar 4 — Sanity Checks & Faithfulness**: Distinguishes visually pleasing heatmaps from truly faithful explanations using randomization tests (Adebayo et al.) and insertion/deletion AUC curves.

### Step-by-Step Worked Example (Read Slowly): Computing Input × Gradient Saliency on a 2-Feature Linear-ReLU Unit

Consider a toy model $f(x_1, x_2) = \operatorname{ReLU}(3x_1 - 2x_2 + 1)$ evaluated at input $x = (x_1 = 2.0,\; x_2 = 1.0)$ relative to baseline $x' = (0, 0)$.

1. **Forward pass**:
   $$f(2, 1) = \operatorname{ReLU}(3(2) - 2(1) + 1) = \operatorname{ReLU}(5) = 5.0.$$
2. **Vanilla Gradient saliency** ($\nabla_x f$):
   $$\frac{\partial f}{\partial x_1} = +3, \qquad \frac{\partial f}{\partial x_2} = -2.$$
3. **Input × Gradient attribution** ($x_i \cdot \frac{\partial f}{\partial x_i}$):
   $$\text{Attr}(x_1) = 2.0 \times 3 = +6.0, \qquad \text{Attr}(x_2) = 1.0 \times (-2) = -2.0.$$
   Notice that $\text{Attr}(x_1) + \text{Attr}(x_2) = 6.0 - 2.0 = 4.0 = f(2, 1) - f(0, 0) = 5.0 - 1.0$ (exact completeness!).
4. **Takeaway**: Raw gradients measure *local sensitivity* (slope), whereas Input × Gradient (and Integrated Gradients on nonlinear nets) accounts for feature magnitude so attributions sum cleanly to the actual prediction shift.
