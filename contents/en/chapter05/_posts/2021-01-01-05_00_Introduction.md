# Introduction to Recurrent Neural Networks

![RNN Unrolled Architecture](/deep-learning-self-learning/img/chapter_img/chapter05/rnn_unrolled_architecture.png)
*Hình ảnh: Kiến trúc RNN ở dạng folded (trái) và unrolled (phải). Nguồn: Wikimedia Commons*

Recurrent Neural Networks (RNNs) represent a fundamental paradigm shift in neural network design: the introduction of **memory**. While feedforward networks and CNNs process each input independently, treating each data point as an isolated sample, RNNs maintain an internal state that evolves as they process sequential data. This seemingly simple addition — allowing information to persist through time — opens up entirely new problem domains: natural language, speech, music, video, time series forecasting, and any task where **order matters**.

The key insight that makes RNNs powerful is their ability to process inputs of **variable length**. A sentence can be 3 words or 30. A video can be 10 frames or 10,000. An audio clip can be 1 second or 1 hour. Traditional neural networks require fixed-size inputs, forcing us to truncate or pad sequences to a uniform length — losing information in the process. RNNs solve this elegantly by processing sequences one element at a time, using the same computation at each step, with a hidden state that carries information forward through the sequence. This design allows RNNs to theoretically handle sequences of arbitrary length while using a fixed number of parameters.

---

## Why Sequential Data Needs Different Architectures

Consider these inputs where order determines meaning:

| Example | Reversed Order | Meaning Change |
|---------|---------------|---------------|
| "The **dog** bit the man" | "The man bit the **dog**" | Subject ↔ Object flipped |
| "The food was **not** bad" | "The food was bad" | Entire sentiment inverted |
| "She only has eyes for him" | "She has only eyes for him" | Literal → Idiomatically different |

This isn't limited to language. In virtually every domain where sequential data appears, context matters:

- **Stock prices**: Yesterday's closing price is today's baseline. Last week's trend informs this week's prediction. The 2008 financial crisis wasn't just about one day's numbers — it emerged from patterns unfolding over months.
- **Speech recognition**: Distinguishing "recognize speech" from "wreck a nice beach" requires temporal context that spans phonemes, not individual sounds.
- **Video understanding**: A ball's trajectory makes sense only in the context of previous frames. Without temporal context, we can't distinguish a ball being thrown versus a ball being caught.
- **Protein folding**: A protein's 3D structure depends on the sequential folding process, not just the amino acid sequence.
- **Musical composition**: A chord's emotional impact depends entirely on what came before. The same chord can sound consonant or dissonant based on context.

**The core challenge**: Feedforward networks treat each input as independent. They have no mechanism to know that word #5 came after word #4. They process "The dog bit the man" and "The man bit the dog" identically — both contain the same words! CNNs can detect spatial patterns but fundamentally lack temporal memory. RNNs solve this by **passing information from one time step to the next** through a hidden state that serves as memory.

---

## The Core Idea: Hidden State as Memory

At each time step $$t$$, an RNN performs a remarkably simple operation:

1. **Receives** a new input $$\mathbf{x}_t$$ (e.g., the next word, frame, or data point)
2. **Combines** it with the previous hidden state $$\mathbf{h}_{t-1}$$ — the network's memory of everything it's seen so far
3. **Produces** a new hidden state $$\mathbf{h}_t$$ — updated memory that now incorporates the new input
4. **Optionally produces** an output $$\mathbf{y}_t$$ — prediction based on what the network has seen

The mathematical heart of the RNN is remarkably simple:

$$\mathbf{h}_t = \tanh(\mathbf{W}_{hh}\mathbf{h}_{t-1} + \mathbf{W}_{xh}\mathbf{x}_t + \mathbf{b}_h)$$

where:
- $$\mathbf{x}_t \in \mathbb{R}^{d_x}$$ is the input at time $$t$$
- $$\mathbf{h}_{t-1} \in \mathbb{R}^{d_h}$$ is the previous hidden state (memory)
- $$\mathbf{W}_{xh} \in \mathbb{R}^{d_h \times d_x}$$ transforms input to hidden dimension
- $$\mathbf{W}_{hh} \in \mathbb{R}^{d_h \times d_h}$$ is the recurrent (hidden-to-hidden) weight matrix
- $$\tanh$$ squashes activations to $$[-1, 1]$$, providing a nonlinearity while preventing explosion

![RNN Unrolled](/deep-learning-self-learning/img/chapter_img/chapter05/rnn_unrolled.png)
*Hình ảnh: RNN unrolled qua các time step, thể hiện hidden state được truyền từ step này sang step tiếp theo.*

### Why This Works: Three Key Insights

**1. Parameter sharing across time**: The same weights $$\mathbf{W}_{xh}$$ and $$\mathbf{W}_{hh}$$ are used at every time step. This is analogous to how CNNs share weights across spatial positions. When the network learns that the pattern "verb follows subject" is important, it learns this once — not separately for each position in the sentence.

**2. The hidden state as compressed context**: The hidden state $$\mathbf{h}_t$$ is a fixed-size vector (e.g., 256 or 512 dimensions) that must encode everything about the sequence up to time $$t$$. This compression is lossy — information must be prioritized. The network learns what information to preserve and what to discard.

**3. Recursive composition**: Because $$\mathbf{h}_t$$ depends on $$\mathbf{h}_{t-1}$$, which depends on $$\mathbf{h}_{t-2}$$, and so on, the hidden state at time $$t$$ theoretically contains information from all previous inputs. This recursive composition is what gives RNNs their theoretical ability to model arbitrarily long-range dependencies — though in practice, gradient decay limits this range.

## Historical Context: Why RNNs Matter

Understanding RNNs isn't just about learning legacy technology. It's about understanding the conceptual journey:

- **1986**: Elman (1990) introduced the Simple Recurrent Network, demonstrating that recurrent connections could learn temporal patterns
- **1997**: Hochreiter & Schmidhuber introduced LSTM, addressing the vanishing gradient problem with gating mechanisms
- **2014**: Cho et al. introduced GRU, simplifying LSTM while maintaining performance
- **2015**: Bahdanau et al. introduced attention, allowing direct connections to any past state
- **2017**: Vaswani et al. introduced Transformers, abandoning recurrence entirely for parallel attention

Each innovation solved problems with previous approaches while maintaining their insights. Understanding RNNs means understanding why each subsequent architecture was developed — and when to use each.

---

## The Road Ahead

RNNs introduced crucial concepts but have fundamental limitations:

| Limitation | Impact | Modern Solution |
|-----------|--------|--------------|
| Sequential processing | Can't parallelize across time | Transformers (attention) |
| Vanishing gradients | Can't learn long dependencies | LSTMs/GRUs (gating) |
| Information bottleneck | Fixed memory loses information | Attention ( direct access) |

These limitations motivated the development of:
- **LSTMs and GRUs** (Chapter 6): Gating mechanisms that create skip connections through time
- **Attention mechanisms** (Chapter 7): Direct connections to any past state without compression
- **Transformers** (Chapter 8): Abandoning recurrence entirely for parallel computation

Understanding RNNs deeply — both their elegance and their limitations — is essential for appreciating why modern architectures evolved the way they did. The RNN isn't just a predecessor; it's the foundation upon which sequence modeling was built.

## Types of RNN Architectures

RNNs can be configured in several ways depending on the task:

| Architecture | Input | Output | Example Tasks |
|--------------|-------|--------|--------------|
| **Many-to-One** | Sequence | Single value | Sentiment classification, intent detection |
| **One-to-Many** | Single value | Sequence | Music generation, image captioning |
| **Many-to-Many (Same)** | Sequence | Sequence (same length) | Part-of-speech tagging, frame-level video classification |
| **Many-to-Many (Diff)** | Sequence | Sequence (different length) | Machine translation, summarization |

## The Three Fundamental Challenges

Despite their elegance, vanilla RNNs face three challenges that motivated subsequent innovations:

### 1. Sequential Processing (Can't Parallelize)
![RNN Black Box](/deep-learning-self-learning/img/chapter_img/chapter05/rnn_blackbox.png)
*Hình ảnh: RNN như một black box với feedback loop — hidden state được truyền ngược lại làm input cho bước tiếp theo.*

Unlike feedforward networks where all samples process independently, RNNs must compute $$\mathbf{h}_t$$ before $$\mathbf{h}_{t+1}$$. This sequential dependency means:
- GPU parallelization provides limited benefit
- Long sequences take time proportional to their length
- **Modern solution**: Transformers use attention to process all positions simultaneously

### 2. Vanishing Gradients (Can't Remember Long Dependencies)
When backpropagating through time, gradients multiply through many layers. If each layer slightly shrinks the gradient (multiplication by < 1), the gradient vanishes exponentially:

$$\frac{\partial \mathcal{L}}{\partial \mathbf{h}_1} = \frac{\partial \mathcal{L}}{\partial \mathbf{h}_T} \cdot \prod_{t=2}^{T} \frac{\partial \mathbf{h}_t}{\partial \mathbf{h}_{t-1}}$$

For a 50-step sequence with a Jacobian eigenvalue of 0.99, the gradient is multiplied by $$0.99^{49} \approx 0.61$$ — essentially zero.
- **Modern solutions**: LSTMs and GRUs use gating mechanisms to create direct "highways" for gradient flow

### 3. Information Bottleneck (Fixed-Size Memory)
The hidden state $$\mathbf{h}_t$$ must encode the entire history of the sequence in a fixed-size vector. As sequences grow longer:
- Information must be progressively compressed
- Details from the beginning are lost
- **Modern solutions**: Attention mechanisms allow direct access to any previous position without compression

These limitations aren't failures — they're insights that drove the evolution of sequence modeling from RNNs → LSTMs → Attention → Transformers.
