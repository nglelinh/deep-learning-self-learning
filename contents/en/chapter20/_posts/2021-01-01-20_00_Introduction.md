Supervised learning hands a model an answer key on every single example; Reinforcement Learning throws an agent into an unfamiliar world with no answer key at all—only delayed scalar rewards that might arrive 50 moves after the decision that actually won or lost the game. That **credit assignment problem** and the tension between **exploring** unknown actions versus **exploiting** known rewards form the mathematical core of sequential decision making.

## Background Knowledge Map: The Architecture of Reinforcement Learning

- **Pillar 1 — Markov Decision Processes (MDPs)**: Formalizes sequential environments as the tuple $(\mathcal{S}, \mathcal{A}, P, R, \gamma)$, where the Markov property states that future transitions depend only on the current state and action.
- **Pillar 2 — Discounted Return & Value Functions**: Measures long-term success via $G_t = \sum_{k=0}^\infty \gamma^k R_{t+k+1}$ and summarizes expected future returns from states ($V^\pi(s)$) or state–action pairs ($Q^\pi(s, a)$).
- **Pillar 3 — Bellman Optimality Equations**: Expresses optimal long-term value recursively as immediate reward plus discounted optimal next-state value, turning infinite-horizon planning into local fixed-point updates.
- **Pillar 4 — Exploration vs. Exploitation**: Balances gathering new information ($\epsilon$-greedy, UCB, Boltzmann exploration) against greedily maximizing current estimates.

### Step-by-Step Worked Example (Read Slowly): Computing Discounted Returns $G_t$ Backward in Time

Suppose an episode lasts 3 steps with rewards $R_1 = 0,\; R_2 = 2,\; R_3 = 10$ and discount factor $\gamma = 0.9$.

1. **Compute returns recursively backward using $G_t = R_{t+1} + \gamma G_{t+1}$** (with $G_3 = 0$):
   - $G_2 = R_3 + 0.9(0) = 10.00$.
   - $G_1 = R_2 + 0.9 G_2 = 2 + 0.9(10.00) = 11.00$.
   - $G_0 = R_1 + 0.9 G_1 = 0 + 0.9(11.00) = 9.90$.
2. **Verify directly from $t = 0$**:
   $$G_0 = 0 + 0.9(2) + 0.9^2(10) = 0 + 1.8 + 8.1 = 9.90.$$
3. **Compare with a myopic discount $\gamma = 0.5$**:
   $$G_0(\gamma=0.5) = 0 + 0.5(2) + 0.25(10) = 1.0 + 2.5 = 3.50.$$
4. **Takeaway**: The discount factor $\gamma$ controls the agent's effective planning horizon $\approx \frac{1}{1-\gamma}$ ($10$ steps for $\gamma=0.9$ vs. $2$ steps for $\gamma=0.5$), directly deciding whether delayed rewards outweigh short-term bribes.

Reinforcement Learning (RL) trains agents to make sequential decisions by maximizing cumulative rewards.
