For nearly fourteen years after Yann LeCun's LeNet-5 began reading millions of bank checks across the United States in 1998, convolutional networks sat largely on the margins of computer vision while hand-crafted SIFT features and support vector machines dominated benchmarks. Then, in September 2012, Alex Krizhevsky, Ilya Sutskever, and Geoffrey Hinton submitted **AlexNet** to ImageNet and shattered the top-5 error rate from $$26.2\%$$ down to $$15.3\%$$—a gap so wide that the entire field pivoted overnight. Comparing LeNet-5 and AlexNet side by side reveals the exact architectural, mathematical, and hardware ingredients that turned a niche digit recognizer into the deep learning revolution.

## Background Knowledge Map: From LeNet-5 (1998) to AlexNet (2012)

- **Activation Functions & Optimization Speed (Sigmoid/Tanh vs. ReLU)**: LeNet-5 relied on saturating `tanh`/sigmoid activations whose derivatives vanish for large magnitudes. AlexNet popularized non-saturating **ReLU** ($$\max(0, x)$$), cutting training time on deep networks by roughly $$6\times$$.
- **Scale of Data, Compute, and Parallelism**: LeNet-5 had ~60K parameters trained on $$32 \times 32$$ grayscale MNIST digits on a CPU. AlexNet scaled to ~61M parameters trained on 1.2M $$224 \times 224$$ RGB ImageNet images across two NVIDIA GTX 580 GPUs (3 GB VRAM each) using grouped convolutions.
- **Regularization for Over-Parameterized Heads**: AlexNet's massive fully connected layers (`9216 -> 4096 -> 4096 -> 1000`) contained over $$95\%$$ of its parameters. Without **Dropout** ($$p = 0.5$$) and aggressive image data augmentation (random crops, horizontal flips, PCA color jitter), the model would have severely memorized ImageNet.
- **Overlapping Max Pooling**: Moving from LeNet's non-overlapping $$2 \times 2$$ average pooling to AlexNet's overlapping $$3 \times 3$$ max pooling with stride $$2$$ preserved sharper discriminative features and modestly reduced overfitting.

### Step-by-Step Worked Example (Read Slowly): Where Do AlexNet's 61 Million Parameters Actually Live?

Let us audit the parameter concentration in AlexNet's first convolutional layer versus its first fully connected layer (using standard $$224 \times 224 \times 3$$ input padded to $$227 \times 227 \times 3$$):

1. **Conv1 (`11x11`, stride `4`, `3 -> 96` filters)**:
   - Spatial output: $$\lfloor (227 - 11)/4 \rfloor + 1 = 55 \implies (96, 55, 55)$$.
   - Parameters: $$96 \times (3 \times 11 \times 11 + 1) = 96 \times 364 = 34{,}944$$ ($$\approx 0.035\text{M}$$).
2. **FC1 (after Conv5 + MaxPool produces `256 x 6 x 6 = 9,216` features $$\to 4{,}096$$ neurons)**:
   - Parameters: $$9{,}216 \times 4{,}096 + 4{,}096 = 37{,}748{,}736 + 4{,}096 = 37{,}752{,}832$$ ($$\approx 37.75\text{M}$$).
3. **Compare FC1 against ALL five convolutional layers combined**:
   - All five Conv layers combined in AlexNet total only $$\approx 2.33\text{M}$$ parameters (~$$3.8\%$$ of the model).
   - FC1 **alone** accounts for $$37.75 / 61.1 \approx 61.8\%$$ of the entire network's weights!
4. **Architectural Lesson**: This exact bottleneck explains why later architectures (GoogLeNet, ResNet) replaced giant flattened FC layers with **Global Average Pooling**, reclaiming tens of millions of parameters while *improving* generalization.

### LeNet-5 (1998) — The Pioneer

LeNet-5 by Yann LeCun was the first successful CNN, designed for handwritten digit recognition.

**Architecture**:
```
Input (32×32×1)
    ↓
Conv1: 6 filters, 5×5, stride 1 → 28×28×6
    ↓
AvgPool: 2×2, stride 2 → 14×14×6
    ↓
Conv2: 16 filters, 5×5, stride 1 → 10×10×16
    ↓
AvgPool: 2×2, stride 2 → 5×5×16
    ↓
Flatten → 400
    ↓
FC1: 400 → 120
    ↓
FC2: 120 → 84
    ↓
Output: 84 → 10
```

**Key characteristics**:
- ~60,000 parameters
- Tanh/sigmoid activations (ReLU didn't exist yet)
- Average pooling (max pooling came later)
- Trained on MNIST (10 classes, 28×28 images)

```python
class LeNet5(nn.Module):
    """LeNet-5 architecture (modernized with ReLU)"""
    def __init__(self, num_classes=10):
        super().__init__()
        
        self.features = nn.Sequential(
            nn.Conv2d(1, 6, kernel_size=5),       # 32→28
            nn.ReLU(),
            nn.AvgPool2d(2, 2),                   # 28→14
            nn.Conv2d(6, 16, kernel_size=5),     # 14→10
            nn.ReLU(),
            nn.AvgPool2d(2, 2),                   # 10→5
        )
        
        self.classifier = nn.Sequential(
            nn.Linear(16 * 5 * 5, 120),
            nn.ReLU(),
            nn.Linear(120, 84),
            nn.ReLU(),
            nn.Linear(84, num_classes)
        )
    
    def forward(self, x):
        x = self.features(x)
        x = x.view(x.size(0), -1)
        x = self.classifier(x)
        return x
```

### AlexNet (2012) — The Deep Learning Breakthrough

AlexNet by Krizhevsky, Sutskever, and Hinton won ImageNet 2012 dramatically and launched the deep learning revolution.

**Architecture**:
```
Input (227×227×3)
    ↓
Conv1: 96 filters, 11×11, stride 4 → 55×55×96
    ↓
MaxPool: 3×3, stride 2 → 27×27×96
    ↓
Conv2: 256 filters, 5×5, pad 2 → 27×27×256
    ↓
MaxPool: 3×3, stride 2 → 13×13×256
    ↓
Conv3: 384 filters, 3×3, pad 1 → 13×13×384
    ↓
Conv4: 384 filters, 3×3, pad 1 → 13×13×384
    ↓
Conv5: 256 filters, 3×3, pad 1 → 13×13×256
    ↓
MaxPool: 3×3, stride 2 → 6×6×256
    ↓
Flatten → 9216
    ↓
FC1: 9216 → 4096 (+ Dropout 0.5)
    ↓
FC2: 4096 → 4096 (+ Dropout 0.5)
    ↓
Output: 4096 → 1000
```

**Revolutionary contributions**:
1. **ReLU activation**: Faster training than tanh/sigmoid
2. **Dropout**: Regularization to prevent overfitting
3. **Data augmentation**: Random crops, flips, color jittering
4. **GPU training**: Split across 2 GPUs (3GB each at the time)
5. **Local Response Normalization**: Lateral inhibition (later replaced by BatchNorm)

**~60 million parameters** — massive for its time!

```python
class AlexNet(nn.Module):
    """Simplified AlexNet"""
    def __init__(self, num_classes=1000):
        super().__init__()
        
        self.features = nn.Sequential(
            nn.Conv2d(3, 96, kernel_size=11, stride=4, padding=2),
            nn.ReLU(inplace=True),
            nn.MaxPool2d(kernel_size=3, stride=2),
            
            nn.Conv2d(96, 256, kernel_size=5, padding=2),
            nn.ReLU(inplace=True),
            nn.MaxPool2d(kernel_size=3, stride=2),
            
            nn.Conv2d(256, 384, kernel_size=3, padding=1),
            nn.ReLU(inplace=True),
            
            nn.Conv2d(384, 384, kernel_size=3, padding=1),
            nn.ReLU(inplace=True),
            
            nn.Conv2d(384, 256, kernel_size=3, padding=1),
            nn.ReLU(inplace=True),
            nn.MaxPool2d(kernel_size=3, stride=2),
        )
        
        self.classifier = nn.Sequential(
            nn.Dropout(0.5),
            nn.Linear(256 * 6 * 6, 4096),
            nn.ReLU(inplace=True),
            nn.Dropout(0.5),
            nn.Linear(4096, 4096),
            nn.ReLU(inplace=True),
            nn.Linear(4096, num_classes),
        )
    
    def forward(self, x):
        x = self.features(x)
        x = x.view(x.size(0), 256 * 6 * 6)
        x = self.classifier(x)
        return x
```
