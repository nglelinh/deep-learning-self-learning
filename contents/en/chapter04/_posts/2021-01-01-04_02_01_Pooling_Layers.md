# Pooling Layers and CNN Architectures

Now that we understand convolutional layers, we need two more pieces to build complete CNNs: **pooling layers** for downsampling and **architecture design patterns** that combine these components effectively. This lesson covers pooling operations in depth and traces the evolution of CNN architectures from LeNet to modern designs.

---

## 1. Pooling Layers: Concept Overview

**Pooling** (also called subsampling or downsampling) reduces the spatial dimensions of feature maps while retaining the most important information. This serves several critical purposes:

1. **Dimension reduction**: Smaller feature maps mean fewer parameters and less computation in subsequent layers
2. **Translation invariance**: Small shifts in the input produce the same pooled output
3. **Noise suppression**: Averaging or taking max reduces sensitivity to small variations
4. **Receptive field growth**: Each pooled pixel represents a larger region of the original input

**Key insight**: Pooling acts as a form of "summarization" — we don't need every pixel of detail to recognize a cat. We need the essential features, and pooling extracts those while discarding redundant information.

## 2. Mathematical Foundation

### Max Pooling

**Max pooling** takes the maximum value in each pooling region:

$$\text{MaxPool}(X)_{i,j} = \max_{m,n \in R_{i,j}} X_{m,n}$$

Where $$R_{i,j}$$ is the pooling region (typically 2×2) at output position $$(i,j)$$.

**Visual example with 2×2 pooling, stride 2**:

```
Input (4×4):              Output (2×2):

┌─────┬─────┬─────┬─────┐
│  1  │  3  │  2  │  4  │     ┌─────┬─────┐
├─────┼─────┼─────┼─────┤     │  6  │  8  │
│  5  │  6  │  7  │  8  │ →   ├─────┼─────┤
├─────┼─────┼─────┼─────┤     │  3  │  4  │
│  0  │  2  │  1  │  3  │     └─────┴─────┘
├─────┼─────┼─────┼─────┤
│  1  │  3  │  2  │  4  │
└─────┴─────┴─────┴─────┘

Region [0:2, 0:2] = [[1,3],[5,6]] → max = 6
Region [0:2, 2:4] = [[2,4],[7,8]] → max = 8
Region [2:4, 0:2] = [[0,2],[1,3]] → max = 3
Region [2:4, 2:4] = [[1,3],[2,4]] → max = 4
```

**Properties of max pooling**:
- Preserves the strongest activations (dominant features)
- Provides some translation invariance
- Introduces a form of non-linearity
- **No learnable parameters**

### Average Pooling

**Average pooling** computes the mean of each pooling region:

$$\text{AvgPool}(X)_{i,j} = \frac{1}{|R_{i,j}|} \sum_{m,n \in R_{i,j}} X_{m,n}$$

**Visual example**:

```
Input (4×4):              Output (2×2):

┌─────┬─────┬─────┬─────┐
│  1  │  3  │  2  │  4  │     ┌───────┬───────┐
├─────┼─────┼─────┼─────┤     │ 3.75  │ 5.25  │
│  5  │  6  │  7  │  8  │ →   ├───────┼───────┤
├─────┼─────┼─────┼─────┤     │ 1.50  │ 2.50  │
│  0  │  2  │  1  │  3  │     └───────┴───────┘
├─────┼─────┼─────┼─────┤
│  1  │  3  │  2  │  4  │
└─────┴─────┴─────┴─────┘

Region [0:2, 0:2] = [[1,3],[5,6]] → mean = 15/4 = 3.75
Region [0:2, 2:4] = [[2,4],[7,8]] → mean = 21/4 = 5.25
```

**Properties of average pooling**:
- Considers all values (no information completely discarded)
- Smoother gradients during backpropagation
- Better for preserving background information
- Less common in classification, more in segmentation

### Max Pooling vs Average Pooling: When to Use Which?

| Aspect | Max Pooling | Average Pooling |
|--------|-------------|-----------------|
| **Preserves** | Dominant features | Overall intensity |
| **Gradients** | Sparse (only through max) | Dense (through all) |
| **Use case** | Classification (find most distinctive) | Segmentation, depth estimation |
| **Modern usage** | Early/middle layers | Global pooling at the end |

**Empirical finding**: Max pooling generally works better for classification because the most distinctive features (maximum activations) are most useful for discriminating between classes.

### Global Average Pooling (GAP)

**Global Average Pooling** averages each entire feature map to a single value:

$$\text{GAP}(X)_c = \frac{1}{H \times W} \sum_{i=1}^{H} \sum_{j=1}^{W} X_{i,j,c}$$

**Visual example**:

```
Input (7×7×512):                    Output (512,):

┌─────────────────────────────┐
│  Feature Map 1 (7×7)        │ →  [0.42]
├─────────────────────────────┤
│  Feature Map 2 (7×7)        │ →  [0.78]
├─────────────────────────────┤
│         ...                 │      ...
├─────────────────────────────┤
│  Feature Map 512 (7×7)      │ →  [0.31]
└─────────────────────────────┘

Each 7×7 map → single number (its average)
Result: 512-dimensional vector
```

**Why GAP is revolutionary** (from Network in Network, 2014):

1. **No fully connected layers needed**: Reduces parameters dramatically
2. **Better generalization**: Acts as structural regularizer
3. **More interpretable**: Each feature map can be directly associated with a class
4. **Input size flexibility**: Model can accept any input size (at inference time)

**Before GAP** (AlexNet, VGG):
```
Conv layers → Flatten (4096 values) → FC (4096→4096) → FC (4096→1000)
Parameters in FC layers: 4096×4096 + 4096×1000 ≈ 20 million
```

**With GAP** (ResNet, modern CNNs):
```
Conv layers → GAP (512 values) → FC (512→1000)
Parameters: 512×1000 = 512,000
```

**40× fewer parameters** just from this change!

### Output Dimensions for Pooling

The same formula as convolution applies:

$$H_{out} = \left\lfloor \frac{H_{in} + 2p - k}{s} \right\rfloor + 1$$

For standard 2×2 max pooling with stride 2:
- $$k = 2, s = 2, p = 0$$
- $$H_{out} = \lfloor (H_{in} - 2) / 2 \rfloor + 1 = H_{in} / 2$$

**Spatial dimensions are halved** (assuming even dimensions).

## 3. Code Implementation

### NumPy Implementation

```python
import numpy as np

def max_pool2d(input_array, pool_size=2, stride=2):
    """
    Max pooling operation.
    
    Args:
        input_array: Input of shape (H, W) or (H, W, C)
        pool_size: Size of pooling window
        stride: Stride of the pooling operation
    
    Returns:
        Pooled output
    """
    # Handle single channel case
    if input_array.ndim == 2:
        input_array = input_array[:, :, np.newaxis]
        squeeze_output = True
    else:
        squeeze_output = False
    
    H, W, C = input_array.shape
    
    # Calculate output dimensions
    H_out = (H - pool_size) // stride + 1
    W_out = (W - pool_size) // stride + 1
    
    output = np.zeros((H_out, W_out, C))
    
    for i in range(H_out):
        for j in range(W_out):
            h_start = i * stride
            w_start = j * stride
            
            # Extract pooling region and take max
            region = input_array[h_start:h_start+pool_size, 
                                w_start:w_start+pool_size, :]
            output[i, j, :] = np.max(region, axis=(0, 1))
    
    if squeeze_output:
        output = output[:, :, 0]
    
    return output


def avg_pool2d(input_array, pool_size=2, stride=2):
    """Average pooling operation."""
    if input_array.ndim == 2:
        input_array = input_array[:, :, np.newaxis]
        squeeze_output = True
    else:
        squeeze_output = False
    
    H, W, C = input_array.shape
    H_out = (H - pool_size) // stride + 1
    W_out = (W - pool_size) // stride + 1
    
    output = np.zeros((H_out, W_out, C))
    
    for i in range(H_out):
        for j in range(W_out):
            h_start = i * stride
            w_start = j * stride
            
            region = input_array[h_start:h_start+pool_size, 
                                w_start:w_start+pool_size, :]
            output[i, j, :] = np.mean(region, axis=(0, 1))
    
    if squeeze_output:
        output = output[:, :, 0]
    
    return output


def global_avg_pool2d(input_array):
    """
    Global average pooling: average each channel to single value.
    
    Args:
        input_array: Shape (H, W, C)
    
    Returns:
        Vector of shape (C,)
    """
    return np.mean(input_array, axis=(0, 1))


# ============== DEMONSTRATION ==============
print("=" * 50)
print("Pooling Operations Demonstration")
print("=" * 50)

# Create sample input
input_data = np.array([
    [1, 3, 2, 4],
    [5, 6, 7, 8],
    [0, 2, 1, 3],
    [1, 3, 2, 4]
], dtype=np.float32)

print(f"Input (4×4):\n{input_data}\n")

# Max pooling
max_pooled = max_pool2d(input_data, pool_size=2, stride=2)
print(f"Max pooling (2×2, stride 2):\n{max_pooled}\n")

# Average pooling
avg_pooled = avg_pool2d(input_data, pool_size=2, stride=2)
print(f"Average pooling (2×2, stride 2):\n{avg_pooled}\n")

# Global average pooling (for multi-channel)
multi_channel = np.random.randn(7, 7, 512).astype(np.float32)
gap_output = global_avg_pool2d(multi_channel)
print(f"Global average pooling:")
print(f"  Input shape: {multi_channel.shape}")
print(f"  Output shape: {gap_output.shape}")
print(f"  First 5 values: {gap_output[:5]}")
```

### PyTorch Implementation

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

# ============== BUILT-IN POOLING LAYERS ==============

# Max pooling
max_pool = nn.MaxPool2d(kernel_size=2, stride=2)

# Average pooling
avg_pool = nn.AvgPool2d(kernel_size=2, stride=2)

# Global average pooling (adaptive - works with any input size)
global_avg_pool = nn.AdaptiveAvgPool2d(1)  # Output size 1×1

# Global max pooling
global_max_pool = nn.AdaptiveMaxPool2d(1)


# ============== DEMONSTRATION ==============
print("PyTorch Pooling Examples")
print("=" * 50)

# Create sample input: batch of 2, 64 channels, 32×32
x = torch.randn(2, 64, 32, 32)
print(f"Input shape: {x.shape}")

# Apply different poolings
max_out = max_pool(x)
avg_out = avg_pool(x)
gap_out = global_avg_pool(x)

print(f"After MaxPool2d(2,2): {max_out.shape}")      # (2, 64, 16, 16)
print(f"After AvgPool2d(2,2): {avg_out.shape}")      # (2, 64, 16, 16)
print(f"After GAP: {gap_out.shape}")                 # (2, 64, 1, 1)
print(f"After GAP + squeeze: {gap_out.squeeze(-1).squeeze(-1).shape}")  # (2, 64)


# ============== POOLING WITH INDICES (for unpooling) ==============

# MaxPool can return indices for unpooling operations
max_pool_with_idx = nn.MaxPool2d(kernel_size=2, stride=2, return_indices=True)
pooled, indices = max_pool_with_idx(x)

print(f"\nMax pooling with indices:")
print(f"  Pooled shape: {pooled.shape}")
print(f"  Indices shape: {indices.shape}")

# Unpooling (useful for segmentation networks like U-Net)
unpool = nn.MaxUnpool2d(kernel_size=2, stride=2)
unpooled = unpool(pooled, indices)
print(f"  Unpooled shape: {unpooled.shape}")


# ============== COMPARISON: POOLING vs STRIDED CONV ==============
print("\n" + "=" * 50)
print("Pooling vs Strided Convolution")
print("=" * 50)

# Traditional: Conv → Pool
conv_then_pool = nn.Sequential(
    nn.Conv2d(64, 128, kernel_size=3, padding=1),  # 32×32 → 32×32
    nn.MaxPool2d(2, 2)                              # 32×32 → 16×16
)

# Modern: Strided Conv (learnable downsampling)
strided_conv = nn.Conv2d(64, 128, kernel_size=3, stride=2, padding=1)  # 32×32 → 16×16

x_test = torch.randn(2, 64, 32, 32)

out_pool = conv_then_pool(x_test)
out_strided = strided_conv(x_test)

print(f"Input: {x_test.shape}")
print(f"Conv + MaxPool: {out_pool.shape}")
print(f"Strided Conv: {out_strided.shape}")

# Parameter comparison
pool_params = sum(p.numel() for p in conv_then_pool.parameters())
strided_params = sum(p.numel() for p in strided_conv.parameters())
print(f"\nParameters - Conv+Pool: {pool_params}, Strided Conv: {strided_params}")
print("(Same parameters, but strided conv learns the downsampling!)")
```
